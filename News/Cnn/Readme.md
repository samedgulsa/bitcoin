## 📡 Veri Kaynağı

**XML Endpoint**
```
https://edition.cnn.com/sitemap/news.xml
```

**Kapsam**
- Son ~48 saat içinde yayınlanan haberler

**⚠️ Uyarı**
- Verinin `publication_date` (haber yayınlanma zamanı) ile sitemap’e düşme süresi kesin değildir
- Testlerde bu gecikme genellikle **en fazla ~2 dakika** olarak gözlemlenmiştir
